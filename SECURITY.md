# Security

Do not report account details, OAuth tokens, API keys, client data, or other secrets in a public
issue.

For security-sensitive reports, contact Glim AI privately through
https://tryglim.ai/contact. For non-sensitive bugs and documentation issues, use the
repository issue tracker.

This package contains public manifests and skills only. The hosted MCP authenticates users with
Glim AI OAuth and remains the security boundary for account data and tool execution.
